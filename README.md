# Reasoning check study

A 30-minute study about how well AI-generated reasoning holds up.
Open the live page and follow the instructions on screen:

**https://amparulekar.github.io/reasoning-check-study/**

Each participant enters their name and the participant number they were given (1–18).
Answers are sent to the organizer when you finish; if sending fails, the last screen
lets you copy them instead.
